# Security Policy

## Supported Versions

Security updates follow the latest stable Hamlet release protocol.

| Version | Security protocol baseline | Supported |
| ------- | -------------------------- | --------- |
| 1.4.8 (latest) | Signed release artefacts, organisation-scoped access enforcement, verified Slack request signing with replay protection, and audited role-restricted administration paths | :white_check_mark: |
| 1.4.6 | Previous stable baseline with critical patch support only | :white_check_mark: |
| 1.4.4 and below | No active security maintenance | :x: |

## Reporting a Vulnerability

To report a vulnerability:

1. Email security findings to **support@mail.hamlet-ai.co.uk** with subject line `Security disclosure`.
2. Include affected version, impacted route or component, reproduction steps, and proof-of-concept details.
3. Do not post exploit details publicly until remediation is confirmed.

Acknowledgement target is within 3 business days. Valid reports are triaged, fixed, and coordinated for disclosure after remediation.
